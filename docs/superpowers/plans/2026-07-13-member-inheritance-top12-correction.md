# Member Inheritance Top-12 Correction Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use $superpower-subagents (recommended) or $superpower-executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking via update_plan.

**Goal:** Replace the incorrect “three A-side selections” inheritance threshold with “three historical general-election top-12 finishes,” then deterministically regenerate every stored inheritance chain.

**Architecture:** Keep all rule changes inside `src/lib/memberInheritance.js`. `getEligibilityAt` will derive top-three, top-seven, and top-twelve counts from dated `electionRanks`; the seeded backfill and runtime graduation flow will automatically consume the corrected eligibility result without UI changes. Historical edges will be cleared and regenerated by the existing backfill script.

**Tech Stack:** JavaScript ES modules, Node test runner, Vite, ESLint, JSON data store.
